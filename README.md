# Demostraciones de Machine Learning

Jupyter Book con cinco demostraciones/ejercicios del curso de Machine Learning.

- **Autor:** Rubiel Velasquez
- **Libro publicado:** https://r041292.github.io/jbook_ml202630_Demostraciones/

## Compilar localmente

```bash
pip install -r requirements.txt
jupyter-book build libro
```

El resultado queda en `libro/_build/html/index.html`.

Cada push a `main` compila y publica el libro automaticamente en GitHub Pages (`.github/workflows/deploy.yml`).

Este libro fue realizado con la asistencia de inteligencia artificial (ver la declaratoria en la introduccion).
